# 调试助手与会话

串口、网络、PID 和摄像头都从「调试助手」进入，创建后直接并列在同一排会话标签中。默认没有会话。

## 新建会话

点击空状态的新建按钮或标签栏 `+`，在内部弹窗中选择类型并填写连接参数。返回可以重新选择类型，取消或按 `Esc` 不会创建标签。

| 分类 | 类型 | 创建后的操作 |
| --- | --- | --- |
| 基础通信 | 串口调试 | 创建后在会话内连接，可先不选择设备 |
| 基础通信 | TCP/UDP 客户端、TCP/UDP 服务端 | 在表单内选 TCP 或 UDP，点击「创建并启动」 |
| 设备调试 | PID 调试、摄像头调试 | 选择串口或网络角色，创建后在会话内连接 |
| 应用协议 | MQTT 客户端 | 填写 Broker 和主题等参数后启动 |

HTTP 客户端和服务端暂时没有新建入口。二进制编辑器位于「嵌入式工具」。

## 管理标签

- 双击标题重命名，拖动标签调整顺序。
- 状态圆点表示该会话的状态，悬停可查看说明。
- 点击标签内 `×`，确认后关闭并等待任务退出。
- 关闭最后一个标签后回到空状态，不自动创建串口会话。

切换标签只切换显示。后台收发、录制和数据累计继续运行；某个会话失败不会断开其他会话。

## 修改连接

先断开或停止当前会话及发送任务，再点击标签栏右侧的连接设置按钮。修改只作用于当前标签，应用后需要重新连接。PID 的通道、曲线滤波和摄像头图像格式等仍在各自内容区设置。

调试助手没有连接预设栏，也不提供这些连接预设的保存或导入导出入口。

## 接收与历史

普通串口和网络会话以接收区为主，底部为固定高度的发送区，发送工具在侧栏中。历史保留最近 1,000 条 / 4 MiB；自动裁剪不减少累计 RX/TX。接收处理跟不上时会明确停止当前连接并显示原因。

要保留完整过程，应在操作前开始[录制](embedded-tools.md#录制与回放)。TCP 接收片段不等于设备应用层帧；HEX 视图只改变显示方式。

完整架构和缓冲上限见[调试助手设计](../DebugAssistantDesign.md)与[资源策略](../performance.md)。
