# 使用指南

EmbedDesk 是面向嵌入式联调的 Windows 桌面工作台。第一次使用可以先阅读[安装与快速开始](getting-started.md)，用两个本机会话完成一次 TCP 收发，再接入真实设备。

指南中的产品截图可点击查看原图，便于核对较小的参数文字。

## 按工作区查找

主界面有五个工作区，工具窗口从对应分类打开。

| 工作区 | 适合做什么 | 使用说明 |
| --- | --- | --- |
| 连接中心 | 通过设备 ID 连接另一台 EmbedDesk，共享串口与 TCP/UDP 服务 | [连接与共享](connection-center.md) |
| 调试助手 | 长时间收发报文、看 PID 曲线或摄像头图像 | [会话管理](debug-assistant.md)、[串口](serial.md)、[网络](network.md)、[PID / 摄像头](pid-camera.md) |
| 远程调试 | 本地 Shell、SSH、远程桌面、文件浏览与编辑 | [终端与文件](remote.md) |
| 网络工具 | 地址计算、连通性排查、测速与局域网文件 | [诊断与测速](network-tools.md)、[局域网文件](lan-files.md) |
| 嵌入式工具 | 芯片烧录、镜像读写、二进制与校验工具 | [烧录与数据工具](embedded-tools.md) |

## 会话与退出

调试标签拥有各自的连接和收发任务。切换标签或工作区时，后台连接继续运行；关闭标签需确认，并释放该标签的资源。收起到托盘也会保留连接，真正退出才等待任务清理。

连接资料与设置的保存范围见[设置与配置管理](settings.md)。遇到问题先看[常见问题](faq.md)，报告问题时附软件版本、操作步骤和脱敏后的错误信息。
