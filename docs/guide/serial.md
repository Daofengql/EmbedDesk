# 串口调试

在「调试助手」中点击 `+` →「串口调试」。可以先创建标签，设备接入后再选择串口。

## 连接设备

1. 选择设备，核对扫描到的描述，避免仅根据 COM 编号判断设备。
2. 按固件要求设置波特率、数据位、校验和停止位。常见配置为 `115200 / 8 / 无校验 / 1`，实际以设备为准。
3. 流控默认关闭，仅在接线和固件都要求时启用硬件流控。
4. 点击连接，确认状态；失败时按错误信息检查占用、权限和设备是否仍存在。

![串口新建表单，展示波特率和串口格式](/images/serial-connection.png)

图中 `COM99` 是隔离测试中的离线示例。实际选择你扫描到的设备；创建标签后再点击会话内的连接按钮。

选择设备或创建标签不会预打开串口；共享预留也不会主动改变 DTR/RTS。对依赖控制线复位或引导的开发板，应核对工具中的控制线设置。

## 普通收发与 Shell

普通模式在接收区查看文本或 HEX，在底部编辑并发送。文本乱码时先核对波特率、编码和固件输出格式；发送二进制时开启 HEX，并核对 CRLF 等附加字节选项。

Shell 模式适合设备的交互式命令行，使用统一终端。模式切换属于同一个串口会话，不会创建第二层标签。

## 循环与队列发送

发送工具侧栏常驻，直接配置循环发送或队列发送。开始前核对间隔和目标内容；修改连接或进行实际串口录制重发前，先停止正在运行的发送任务。

显示历史有容量上限，长时间采集应使用录制，不能将接收窗口当作完整原始存档。

## 远程串口与占用

连接中心授权成功后，对方发布的串口会出现在设备列表中，应用内使用无需虚拟串口驱动。先由被连接方[发布共享串口](connection-center.md#共享串口)，再按相同流程设置并打开。

同一个串口不能同时由本地调试、烧录和远程使用。共享预留会阻止本应用内的本地打开，但不能阻止其他程序占用物理 COM。使用其他软件访问远程 COM 时需单独配置[实验性系统虚拟串口](../VirtualSerialPorts.md)。
