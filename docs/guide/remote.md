# 远程终端与文件

「远程调试」默认显示本地 Shell，也可以保存远程连接，双击后在新标签中连接。

## 本地与 SSH 终端

使用本地 Shell 入口可以多开 PowerShell / CMD。连接远端时点击新建，在弹窗中填写名称、协议、主机和端口；SSH 可选密码或私钥认证。保存后在连接列表中双击打开，也可从弹窗直接打开。

核对 SSH 主机密钥后再接受新主机。标签会先显示握手过程，成功后进入终端；失败保留错误，按提示检查地址、端口和认证方式。

本地与 SSH 终端都支持颜色、交互式 TUI、复制粘贴、右键菜单、清屏和全屏。`Ctrl +` / `Ctrl -` 调整字号。窗口、面板或字号变化会同步实际 PTY 行列数。

切换标签不会关闭终端。标签可拖动排序，关闭使用标签内 `×` 并确认。

## SSH 文件工作区

1. SSH 连接成功后展开底部「文件」区域，默认处于折叠状态。
2. 宽布局中左侧是本地目录，右侧是远程目录；使用 `..` 返回上级，通过右键菜单执行文件操作。
3. 按实际需要上传或下载。小文本和图片可下载到缓存后在新标签中预览或编辑，默认上限 5 MiB。
4. 编辑后保存到远端，确认成功反馈再关闭文档。

只拖动「文件」标题区域可以将面板拖出为独立窗口，再合并回来。面板边缘中部按钮负责收起和恢复；终端自己维护滚动区域。

## 远程桌面与其他协议

| 类型 | 当前使用边界 |
| --- | --- |
| RDP | 使用系统 MSTSC ActiveX，需要目标已启用并允许远程桌面 |
| VNC | 内置 RFB 3.3 / 3.7 / 3.8，支持 Raw / CopyRect / DesktopSize；无 TLS / VeNCrypt |
| Telnet | 用于已有 Telnet 服务，连接内容不加密 |
| S3 | 提供 HTTPS 对象浏览、上传下载、删除和分段上传；尚无真实服务验收 |

VNC 标准密码只使用前 8 个 Latin-1 字符。不要把能打开连接表单等同于支持所有远程桌面扩展。S3 当前没有 ACL 管理、预签名分享或断点续传。

## 连接质量提示

连接质量探测失败不会修改会话连接状态。默认 TCPing 会额外建立短连接，可在设置中切换为 ICMP 或关闭；排查会话问题时仍应以该会话的握手、收发和错误信息为准。
