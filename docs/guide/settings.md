# 设置与配置管理

点击主窗口右上角设置按钮。设置用于保存偏好和连接资料，活动连接仍由各自会话管理。

## 中继、代理与连接偏好

在「中继服务器」中添加服务器、选择默认节点并查看异步延迟探测结果。连接选项保存后下次上线生效，取消不保存。启动自动上线，没有额外的自动连接开关。

![设置中的中继服务器列表、默认节点和探测状态](/images/settings-relays.png)

填写名称、地址和该节点的准入 Token 后添加，再选中设为默认并保存；未启用准入的节点可留空 Token。也可复制管理员提供的连接代码，点击「导入连接代码」，核对后点击「添加」或「更新」再保存。同一地址会更新原条目；取消设置不提交导入内容。图中是未启动测试中继的回环示例，显示「不可用」；使用时替换为你部署的实际地址，检查探测结果和错误。

每个中继独立保存准入 Token，「连接选项」不再提供全局准入密钥。编辑已有条目时，清空 Token 并点击「更新」可移除该节点的准入凭据。选中条目点击「复制连接代码」可提供给其他获准接入的人，代码含 Token，Base64 编码不提供加密。测速仅检查服务健康和延迟，Token 是否有效在实际注册时验证。

代理支持直连、系统代理和自定义代理。「连接安全」管理设备访问授权与密码，额外根证书仅用于 HTTPS 链路信任，与中继准入 Token 分开。HTTPS 仍检查主机名和证书链，没有忽略 TLS 错误的开关。具体链路边界见[设备连接说明](../DeviceConnections.md)。

## 保存了什么

| 内容 | 保存与恢复行为 |
| --- | --- |
| 窗口、工具偏好、中继列表、共享服务与映射规则 | 保存到本机应用设置；规则恢复不等于监听已开启 |
| 命名远程连接 | 保存非敏感连接资料；不会自动恢复活动会话 |
| SSH 私钥 | 保存路径索引，不复制私钥内容 |
| 设备凭据、静态密码、每个中继的准入 Token 和可选 S3 密钥等 | 使用 Windows 凭据管理器，不写入普通 JSON 设置 |
| 调试收发历史、发送载荷、普通会话密码 | 不作为普通设置保存 |

旧设置会自动迁移；旧全局准入密钥在下次保存设置时按已有中继分别保存，新添加的节点不继承该密钥。调试助手已经移除连接预设入口，历史预设记录仅保留读取兼容。

## 配置导入导出

配置包用于命名远程连接和旧桥接 / STCP 资料的迁移。导入时先预览，再确认合并；不要将配置包视为完整的运行状态备份。

产品入口不导入或导出调试助手 / 网络旧预设，也不导出密码、私钥路径、密钥口令、凭据索引、活动会话或连接中心的新共享服务与映射。配置加载不会恢复设备授权或实际 COM 打开状态。

## 关闭与托盘

主窗口关闭时默认询问收起到托盘、退出或取消，可记忆选择。收起保留原窗口、连接和后台任务；双击托盘图标恢复。真正退出会处理未保存内容和活动连接，再等待清理。

存储结构和 schema 版本见[架构中的配置与生命周期](../Architecture.md#配置与生命周期)。
