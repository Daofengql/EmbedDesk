# 烧录、镜像与数据工具

「嵌入式工具」按对象分类，点击卡片打开独立工具窗口。先核对型号与支持范围，再选择接口和镜像。

![嵌入式工具中的芯片烧录、存储介质与数据工具入口](/images/embedded-tools.png)

按目标芯片选择上方烧录卡片；二进制编辑器、CRC 和编解码在「数据与调试辅助」中。滚动可查看下方工具。

## 芯片烧录

| 入口 | 当前支持范围 |
| --- | --- |
| ESP 烧录工具 | ESP8266、ESP32 / S2 / S3 / C2 / C3 / C6 / H2 的 UART ROM 功能 |
| STM32 烧录工具 | AN3155 USART；探针入口仅为 USB 拖拽盘 |
| C51 烧录工具 | 原始 STC89 白名单 UART ISP；设备块校验不等于 Flash 回读 |
| CH347T 烧录工具 | Windows 原生 HID，明确的 NOR / NAND 芯片表见[专项说明](../ch347-spi-support.md) |

开始前按工具界面选择设备与镜像，检查识别结果、容量、地址范围和命令支持，再确认擦写。串口如已用于调试或共享，应先解除占用。未知型号不尝试破坏性写入。

取消会停止后续操作，不能回滚已擦除或写入的数据。操作结束后查看实际结果与校验报告。ESP 分区备份不是文件系统 / NVS 编辑；CH347T NAND 保留物理块布局，不自动重映射坏块。

## SD / USB 原始镜像

选择目标介质和镜像后，核对设备、容量与写入范围，再确认写盘。此工具执行原始写入和读回校验，不等同于完整 Rufus 或 Windows 安装 ISO 转换。不要依据盘符或相似名称直接确认目标。

FAT32 格式化当前范围为 256 MiB–2 TiB、512 B 扇区。写盘和格式化会改变目标内容，按工具中的确认提示操作。

## 二进制与校验

「二进制编辑器」用于连续 HEX / ASCII 查看、搜索定位、覆盖编辑、撤销与重做。编辑期间不改原文件，保存完成后才替换目标。当前不支持插入或删除字节；`.hex` 按原始字节读取，不解析 Intel HEX 记录。

「CRC / 校验工具」计算报文或文件校验值；「HEX / 编解码工具」处理 HEX、Base64 和文本互转。算法名称、初值、反射方式和字节序应与设备协议一致。

## 录制与回放

在通信会话中开始录制，可将显示裁剪前的原始 RX/TX 与时间信息保存为 `.edbgtrace`。从「日志与回放」打开录制文件，按原始节奏以 0.25–8× 速度回放。

单次录制上限为 64 MiB / 100,000 条，磁盘跟不上时明确停止。实际串口重发只发送 TX，并与其他发送任务互斥；回放前先确认目标设备与报文不会触发非预期操作。

协议模拟、回环和文件流测试不能替代开发板、Flash 或物理磁盘实测。开发验证范围见[构建与验证](../development/index.md)。
