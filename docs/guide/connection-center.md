# 连接中心与共享

连接中心用于让另一台 EmbedDesk 访问本机发布的串口或 TCP/UDP 服务。两端使用设备 ID 授权连接，程序自动尝试局域网直连，失败后回退到中继。

## 准备中继与授权

1. 先准备[自部署中继](../../server/relay/README.md)，或使用你有权访问的中继。软件没有预置公共节点。
2. 在右上角设置 →「中继服务器」添加地址，选择默认节点；需要时填写准入密钥。保存后下次上线生效。
3. 应用启动后自动上线，在连接中心查看设备 ID 和连接密码。
4. 连接方填写对方 ID 与密码。密码留空会请求对方人工授权，等待期间可以取消。

两端应使用同一中继。即使准备使用局域网直连，设备 ID 查询和初始授权仍依赖中继。公网部署应使用 HTTPS 反向代理，人工授权依赖可信中继与链路。

## 共享串口

在被连接方的「映射设置」中点击「添加串口」，选择设备并发布。连接方授权后，对方的 COM 会出现在串口选择列表中；选择它，填写参数并连接即可。

启用共享只做应用内软件预留，不会提前打开设备或改变 DTR/RTS。连接方实际打开时才提交串口参数，被连接方成功打开后才算连接成功。远端关闭后释放硬件，共享预留保留；本地要重新调试或烧录，需要取消共享。

应用内远程串口无需驱动。如果必须让其他软件看到系统 COM，另看[系统虚拟串口（实验性）](../VirtualSerialPorts.md)。

## 发布网络服务

在被连接方点击「添加服务」，选择 TCP 或 UDP，填写目标主机和端口。目标可以是被连接方本机，也可以是它能访问的网络设备。

连接方建立设备会话后，在「映射设置」选择对端已发布服务，填写本机回环端口并保存、启用。映射方向始终如下：

```text
连接方 127.0.0.1:LOCAL_PORT
    → 对端已发布的 TCP/UDP 服务
    → 被连接方可访问的 HOST:PORT
```

之后在本地工具中访问这个回环端口。监听启用只代表本机端口已准备，首次实际访问才打开对端目标通道；失败时查看映射状态和真实错误。

映射不是任意网段 VPN，也没有反向映射选择。授权设备会话可以访问对端当前发布的全部服务，应只发布本次需要的目标。

## 掉线与退出

重连只恢复节点上线，不恢复设备授权、实际串口或活动映射监听，需要重新连接和启用。收起到托盘会保留连接和共享预留；真正退出才清理任务。

UDP 映射通过认证 TCP 直连或加密 WebSocket 转发，不是 UDP 打洞。容量、限速和认证细节见[设备连接与安全边界](../DeviceConnections.md)。
