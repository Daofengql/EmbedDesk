## 尚未实现或待验收

| 方向 | 缺口 |
| --- | --- |
| 公共中继与公网连接 | 正式公共节点、IPv6 直连、UDP 打洞、脱离中继的发现 / 授权、路径无缝迁移 |
| 配置迁移 | 新共享服务和映射规则的导入导出、跨设备同步及凭据策略 |
| 文件与对象 | 跨公网局域网文件通道；S3 匿名桶、ACL / 策略、预签名分享、断点续传和真实 AWS / 兼容端点验收 |
| iperf3 | 多流、双向同时、SCTP、认证、CPU / TCP 重传统计和标准 CLI 到内置服务端的互通 |
| 固件与介质 | 更多型号需先补协议和芯片表；现有实现不扩展为通用 SWD、C51、NAND 或完整 Rufus |
| 桌面兼容 | 完整 RDP 登录、不同 VNC 服务端、真实 com0com / 第三方串口软件和跨机防火墙场景 |
| 应用更新 | 签名、密钥轮换、失败回滚和退出替换方案；当前只有 GitHub 默认浏览器入口 |

## 验证边界

现有回归主要使用本机 Go / .NET、临时数据库、TLS 终止夹具、回环网络、模拟 COM 和文件流。Smoke 项目需单独构建，入口和命令见[首页开发与验证](../README.md#开发与验证)。这些检查不能替代公网 Nginx 部署、真实代理、跨机局域网、开发板、Flash、物理磁盘、完整 RDP 登录或生产 S3 验收。

iperf3 公共对端记录保留原始来源和验证日期，不代表当前可用或全版本兼容；协议边界见 [iperf3 说明](third-party/iperf3-protocol.md)。每次报告应区分编译、自动测试、截图检查、真实互通和硬件实测，未执行的入口不能记为通过。
